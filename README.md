# Counter-Strike: Global Casino & Lootboxes 🎮🔫

Interaktivní webová aplikace v Counter-Strike (CS2 / CS:GO) stylu s herními automaty (Slot Machine) a otevřením lootboxů (Case Opening).

## Funkce
- **CS:GO / CS2 Lootboxy (Case Opening)**: Otevírání beden s animovaným caseline navijákem, raritami zbraní (Mil-Spec, Restricted, Classified, Covert, Special Rare Knife/Gloves) a možností získané skiny si uložit nebo prodat.
- **CS Slot Machine (Herní Automat)**: 3-válcový automat s CS tématikou (AWP Dragon Lore, Karambit, C4, Bomb Defuse, Headshot, StatTrak) s násobiči výher.
- **Inventář & Ekonomika**: Sledování zůstatku CS bodů / coinů, prodej skinů z inventáře a možnost získat denní bonusy.
- **CS UI & Audio**: Tmavý taktický HUD design a zvukové efekty generované pomocí Web Audio API.
